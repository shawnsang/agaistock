股票复盘教练 · 设计说明

一个会挑你毛病的复盘教练，
不是又一个记笔记的 App。

你对着手机说三十秒心里话，它把这句话变成一条结构化的观察； 然后用几个互相独立的角度去审视这条观察——哪些是你没查过的数据、哪些是逻辑跳跃、 哪些是你反复犯的老毛病；接着它替你定好「几号回来验证、什么算对」； 到期那天自动给你一张结算单，告诉你哪条判断错了、错在哪一类、这次打几分。 一年之后你手里有的不是笔记，是一份关于「你为什么会判断错」的档案。

整件事只有这一个循环

所有功能都挂在这条闭环上。任何不服务于它的东西，都不往里放。

它和你现在用的复盘笔记，差在哪

差别不在「能不能记录」，在于记录之后有没有东西对你产生反作用。

普通复盘笔记 App这个 App
你说的话存下来拆成主张 / 依据 / 证伪条件三块
有没有人反驳你没有，只有你自己回看五个独立透镜，各挑各的毛病
数据从哪来你自己截图粘进去自动取行情/资金/财务，引用可溯源
证伪条件一般不写没有就判「致命缺陷」，逼你补上
过一阵子躺在那儿自动到期结算，对错归因打分
一年后你有一堆笔记一份「你为什么会判断错」的档案
分数的含义—你的观察质量（0–100）
股票涨跌和分数的关系—完全分开：跌了 ≠ 你观察得差

你的一天，具体怎么过

两个模式：随时随手记，和收盘后批量复盘。都能开，按当天状态切。

早盘前 · 随手记模式
00:32

「章源钨业我看了三年了，钨价从去年就开始涨，公司储量排前列，明年上半年产量能翻倍。我觉得还能拿半年。」

你说的话里没有「什么情况下我错」。它不会替你想一个——这条观察会被标成「证伪条件缺失」，这是最该改的一处。
  1. 08:40 · 盘前

    说一句话，30 秒

    打开 App 按一下麦克风，说完。它把语音转成文字，同时拆成一张结构化观察卡。你扫一眼就知道它理解对了没有——理解错了当场改。

  2. 08:41 · 盘前

    看它挑你的毛病

    五个透镜同时审这条观察：一条条断言去查数据、因果链有没有跳、证伪条件够不够、像不像你以前的老毛病、和真实盘面冲不冲突。结论直接列成清单，每条都带「怎么改」。

  3. 08:42 · 盘前

    收下观察期

    它按信号强度给你定一个回访日，并写下到期时怎么算对：哪几个指标要满足什么条件。这套判定标准一旦写下就锁死，到期不许改——不然就是自己给自己找台阶。

  4. 15:30 · 收盘后（批量模式）

    一键今日复盘

    自动拉当天全部行情和资金数据，把你这周所有观察过一遍：哪些还在跟踪期、哪些到期了、哪些已经证伪。给你一张总表，而不是十条散落的笔记。

  5. 到期当天

    结算单

    App 自己按当初写下的标准逐条核对，出结算单：哪条 check 命中、哪条没中；方向对不对、时机早没早、幅度差多少；然后给出归因和这次的观察分。

  6. 每周日

    认知档案更新

    你的偏差标签在累积，「看多准确率 vs 自评信心」的校准曲线在动。一周结束时它告诉你：这段时间你最大的认知漏洞是什么，下周专盯哪一维。

查了最新公告和研报，没有产能指引。这条目前只是你的预期，不是事实。
怎么改标注为假设，并写下「什么信号出现才说明它成立」。
与实际盘面冲突 重要
数据锚点显示当前处于 S3 主升阶段末段：DDZ 已从 28 回落到 17，超大单近 3 日转为净流出。
怎么改把「还能拿半年」改成条件句：资金流维持则持有，DDZ 跌破 15 则减半。
因果链缺一环 次要
「储量前列」到「产量翻倍」之间缺了矿权/开采指标这一环，中间跳步了。
追高锚定 次要
你 3 天前的观察是「等回调再买」，现在改成「还能拿半年」，中间的转折没有理由。
怎么改说明是什么变化让你改了主意。

它跑在哪、用什么

桌面本地安装，数据全在你自己的机器上，不上云、不需要账号。

界面Mini App 面板（P1）· 手机 App（P3）
接入标准 MCP Server，任何 AI 宿主都能挂
技能每个审阅透镜一个 SKILL.md，可增可改
模型DeepSeek / GLM / MiniMax 可切换
数据通达信 MCP + 本地缓存 + SQLite
不需要公网服务器，也不需要云。 MCP server 就是你电脑上被 AI 宿主拉起的一个本地子进程（stdio），不监听端口。你的观察记录、评分、认知档案全在一个本地 SQLite 文件里，备份就是拷那个文件。真正会出网的只有两样：口述文本发给大模型、行情查询发给数据商。
为什么要拆成 MCP 这一层：业务逻辑和「用哪个 AI 宿主」解耦。哪天你想换模型、换工具、或者搬到手机上，不用重写任何分析逻辑——这也是为什么这套东西不会随某个工具改版就报废。

落到第一版，先做哪一块

第一个可用版本不做花哨界面，只保证这条链是通的：

第 1 步
数据层 + 观察卡

接一个行情连接器 + Tushare 兜底，落本地缓存。语音/文字进结构化观察卡。

第 2 步
五个透镜 + 评分

审阅、扣分、给改进建议。复用你已有的 7 维引擎当客观锚点。

第 3 步
观察期 + 到期结算

定时任务自动回访，出结算单和归因。闭环成立。

界面（P1）、认知档案看板（P2）、手机端（P3）都在后面。先把闭环跑通，不然很容易做出一个漂亮但没用的记账本。
